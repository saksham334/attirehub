# AttireHub

A colorful, modern full-stack clothing e-commerce platform built with the MERN stack
(MongoDB, Express, React, Node.js).

> Work in progress. This is a portfolio project.

## Planned Features

- Product catalog with search, filters and sorting
- User authentication (JWT) with role-based access
- Shopping cart and wishlist
- Demo checkout flow and order history
- Admin dashboard for products, inventory, orders and users

## Tech Stack

- **Frontend:** React, Vite, Bootstrap, React-Bootstrap
- **Backend:** Node.js, Express
- **Database:** MongoDB, Mongoose
- **Auth:** JWT, bcryptjs

## Project Structure

- `client/`: React frontend
- `server/`: Express API

Full documentation (installation, API reference, screenshots) will be added as the project grows.
